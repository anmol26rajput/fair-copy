# Fair Copy

Integrity tools for a thesis draft: a source-overlap checker, an AI-use tracker with a disclosure statement, and a guided rewrite coach. They point out problems and help the student write in their own words; they never paraphrase text or try to lower a detector's score.

- [`web/`](web/): the website. Static, runs fully in the browser, files never leave the device. Deployed on Vercel.
- [`thesis-tools/`](thesis-tools/): the same three tools as Python command-line scripts.
